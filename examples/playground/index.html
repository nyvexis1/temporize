temporize playground

Each demo below is a few lines in src/main.ts. Change the numbers, break things, and see what happens. The "server" is fake, so nothing leaves your browser.

debounce: await the result

Type quickly. Only the last keystroke reaches the server, and you get its result back.

    debounceAsync: cancel the stale request

    The server takes 800 ms. With overlap: "cancel-previous", a new search aborts the one still in flight, so an old answer can never overwrite a newer one.

    retry: survive a flaky API

    This endpoint fails about two times out of three. retry waits a bit and tries again.

      concurrencyLimit: at most 3 at a time

      Ten uploads start together, but only three run at once. The rest wait their turn.
